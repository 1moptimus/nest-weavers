# Nest Weavers

Website for Nest Weavers, an interior design firm (replaces the static site at https://nestweavers.com).

Astro + React islands + Tailwind CSS, deployed as a static site on Cloudflare Pages.

## Getting started
```bash
nvm use        # Node 22
npm install
npm run dev    # http://localhost:4321
```

## Scripts
`dev`, `build`, `preview`, `check`, `format` – see `package.json`.

## Deploy (Cloudflare Pages)
- Build command: `npm run build`
- Output directory: `dist`
- Environment variable: `NODE_VERSION=22`
